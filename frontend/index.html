    Frequently asked questions

    Is GlobalTest free?

    Yes. GlobalTest is free to use and you don't need an account.

    Does it use a real browser?

    Yes. Each test starts a real Chrome browser in the country you chose, so JavaScript runs and the page is drawn the way a visitor's browser would draw it. It is not a plain HTTP request.

    Is this a VPN or a proxy?

    No. The browser itself runs on a server inside the country, in an Amazon Web Services data centre, so the website sees a visitor from that country. Some sites treat data centre visitors differently from home broadband visitors.

    What does the load time measure?

    The time from the browser starting to open your address until the page is ready and the screenshot has been taken.

    How long does a test take?

    Usually under a minute. Most of that is the browser starting up in the country you picked. A page that hasn't loaded after 45 seconds is reported as failed.

    Can I test a mobile view, or a page behind a login?

    Not yet. Tests use a desktop window 1280 pixels wide and 720 pixels high and open only public addresses, without signing in.

    Do you keep my screenshots?

    Screenshots are deleted automatically one day after the test.
